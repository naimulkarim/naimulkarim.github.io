# Naimul Karim — Portfolio

A responsive, static portfolio website for GitHub Pages. Built with HTML, CSS, and vanilla JavaScript; no build step or framework required.

## Files

- `index.html` — page content
- `styles.css` — responsive layout and styling
- `script.js` — mobile navigation and dynamic copyright year
- `assets/favicon.svg` — site icon

## Publish with GitHub Pages

1. Push these files to the root of the `main` branch in `naimulkarim/naimulkarim.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the deployment to finish, then visit https://naimulkarim.github.io.

## Before sharing the site

- Replace the generic LinkedIn URL in `index.html` with your actual profile URL.
- Review the experience and project descriptions for accuracy.
- Replace placeholder project links with specific public repositories or live demos.
- Add a resume PDF only if you want it publicly downloadable; link it from the page.
- Do not publish private employer code or confidential information.

## Local preview

Open `index.html` in a browser. For a closer local-server preview, run `python -m http.server 8000` from this directory and open `http://localhost:8000`.
